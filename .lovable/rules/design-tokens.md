# Design Tokens

Token reference for **myhealth checkup**. Use utility classes and CSS variables — never raw values.

## Colors

Apply with any color utility: `bg-<name>`, `text-<name>`, `border-<name>`, `ring-<name>`, `divide-<name>`, etc.

| Name | CSS variable |
|---|---|
| `brand-turquoise` | `--color-brand-turquoise` |
| `brand-pink` | `--color-brand-pink` |
| `brand-navy` | `--color-brand-navy` |
| `surface-warm` | `--color-surface-warm` |

## Typography

Typography classes (`font-*` for families, `text-*` for sizes):

| Class | CSS variable |
|---|---|
| `font-heading` | `--font-heading` |
