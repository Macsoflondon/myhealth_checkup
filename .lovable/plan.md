# Curate a six-slide real-photo hero sequence

## Direction
Create a six-slide sequence that alternates between three existing image-only slides and three new real-stock photographs with short embedded slogans.

```text
Existing image → New slogan image → Existing image → New slogan image → Existing image → New slogan image
```

Use only authentic photography from reputable free commercial-use libraries. Record the source URL, photographer and licence for every selected image. Do not use AI-generated or AI-modified people.

## Three proposed new image-and-slogan options

1. **Wellness and informed choice**
   - Image: a health-conscious UK adult in their 30s–40s, active but natural rather than staged, with generous negative space for type.
   - Slogan: **“Your health. Your choice. Compare with confidence.”**
   - Supporting line: **“Private health tests, clearly compared.”**

2. **Longevity and healthy ageing**
   - Image: an energetic midlife or older couple outdoors, candid and contemporary, avoiding generic retirement imagery.
   - Slogan: **“Plan well for the years ahead.”**
   - Supporting line: **“Compare tests for health, wellbeing and longevity.”**

3. **Private cancer screening clarity**
   - Image: a calm adult in a bright, credible consultation or screening environment; reassuring without implying diagnosis or treatment.
   - Slogan: **“Private screening, made clearer.”**
   - Supporting line: **“Compare options, prices and providers in one place.”**

All copy remains calm, specific and evidence-led. It will not promise outcomes, imply diagnosis or suggest that myhealth checkup provides medical care.

## Review stage — no homepage changes yet
- Shortlist suitable photographs from free commercial-use stock sources and verify that each permits website and promotional use.
- Build three polished preview compositions using the actual photographs, brand typography, navy contrast treatment, turquoise emphasis and restrained pink detail.
- Prepare desktop and mobile-safe crops so faces and embedded text remain fully visible.
- Present all three finished previews together with their source and licence details.
- Wait for explicit approval or requested revisions before adding any image to the site.

## Homepage implementation after approval
- Retain the jogging, blood-test-kit and gym images as the three existing slides; remove the senior-couple and bench-phone slides from the rotation only after the new set is approved.
- Interleave the three approved slogan images as slides 2, 4 and 6.
- Add responsive AVIF/WebP versions and preserve deferred loading so the first slide remains the only priority image.
- Keep the current rotation timing, transitions, reduced-motion behaviour and section borders unchanged.
- Add descriptive alternative text for each photograph without repeating the visible slogan.

## Verification
- Review the complete six-slide sequence on desktop and mobile.
- Check every crop for text clearance, contrast, face visibility and no overlap with homepage controls.
- Confirm all three slogans appear on alternating slides only.
- Confirm there is no horizontal overflow, noticeable image-layout shift or regression to first-load performance.
- Run focused type checks and the existing homepage browser check before completion.
